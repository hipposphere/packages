# 0.1.0

- Initial local prototype: Flutter feature harness, visual checkpoints, HTML
  report, machine results, and failure-path verification.
- Support full-app resource cleanup, clock-aware completion, and pinned SDK
  Roboto loading for readable Material rendering.
- Bundle a reusable Jaspr report inspector with golden comparison modes, zoom,
  scenario filtering, step/checkpoint replay and MP4/WebM attachment playback.
- Add opt-in `--record-steps` capture and `--report` regeneration, versioned JSON,
  escaped report data and standalone viewer assets.
